# Dhamma-Books Daily Chant PCED pilot — revision 2

Upload these three files to the root of `PAMCSG/Dhamma-Books`, preserving the filenames:

- `daily-chants.html`
- `pced-lookup-core.js`
- `pced-standard-data.js`

This package is limited to the approved Daily Chant English pilot. It does not replace other book HTML files.

The shared resolver is version 2.2.0. The shared verified-data supplement is revision 2. It adds the tested PCED forms/headwords needed for `maṅgalaṁ`, `bhaṇāma`, `obhāsetvā`, `acintayuṁ`, `sevanā`, `bālānaṁ`, and `viharanti`.
