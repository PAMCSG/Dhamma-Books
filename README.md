# Dhamma-Books Daily Chants PCED pilot — revision 3

Upload these three files to the root of `PAMCSG/Dhamma-Books`, preserving the filenames:

- `daily-chants.html`
- `pced-lookup-core.js`
- `pced-standard-data.js`

This package changes only the approved English `daily-chants.html` pilot. It does not replace any other book HTML file or the repository index.

Revision 3 uses shared lookup core 3.0.0 and pilot-wide standard data `2.0.5.0-pilot-wide-r3-2026-09-04`. The examples reported during testing are regression cases, not isolated exceptions. Regular noun/adjective declensions and verb conjugations are generated by family, and a result is accepted only when the complete candidate is an attested PCED headword. No prefix, substring, or fuzzy result is allowed.

The supplement contains the official PCED entries required by the resolver across the complete Daily Chants and Kūṭadantasutta pilot token audits. Keep `pced-lookup-core.js` and `pced-standard-data.js` identical in all PCED-enabled repositories when the later repository-wide rollout is approved.
